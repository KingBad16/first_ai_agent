created my first ai agent using python and gave it few tools like wikipedia for collecting data
<br>
Setup instructions :
</br>
<br>
after cloning create .env file and paste your OPENAI_API_KEY/ANTHROPIC_API_KEY 
</br>
<br>
install virtual environment "python -m venv env"
</br>
<br>
install requiremnts.txt "pip install -r requirements.txt"
